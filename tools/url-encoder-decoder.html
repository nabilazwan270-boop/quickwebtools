URL Encoder Decoder

Encode full URLs or components, then decode them back instantly.

Use Full URL for links, and Component for query values or text fragments.

How it works:
• encodeURI keeps characters like :, /, ?, & in a normal URL.
• encodeURIComponent is stricter and is better for query values or small text parts.
• decodeURIComponent converts encoded text back to readable form.
